# Fallout TTRPG - Scheda Personaggio Interattiva Vault-Tec

Scheda personaggio interattiva e compendio digitale completo per il gioco di ruolo cartaceo **Fallout TTRPG (Arcane Arcade 2.1)**.

## Caratteristiche
- **Pip-Boy 3000 Mk IV OS**: Interfaccia reattiva con temi Vault-Tec (bianco/grigio ad alto contrasto), Cartaceo ed Enclave.
- **Regolamento Completo 2.1**:
  - Compendio ufficiale con 186 Perk con traduzione italiana verificata e testo originale in inglese.
  - Catalogo completo di 42 armi ufficiali con munizioni speciali, modding avanzato e calcolo danni.
  - Armature e Power Armor complete con modificatori SPECIAL e consumi.
  - Sistema ufficiale Radiazioni (CD = 12 - Mod. Endurance, danni permanenti a PF/PA, test radiazioni e tiro salvezza trasformazione Ghoul a CD 20).
- **Funziona al 100% Offline**: Nessun server o database necessario, i dati del personaggio vengono salvati nel browser (`localStorage`) con esportazione/importazione JSON.

## Utilizzo su Smartphone
Può essere aperta direttamente dal browser del cellulare o aggiunta alla schermata Home come Web App.
